# パンアカウント（@muku_pan_）ナレッジ置き場のルール

このフォルダは、パンのアカウント @muku_pan_ の Instagram の投稿と、調べたこと（検索パターン）を記録し、
「次に活かせる知識（ナレッジ）」に育てるための場所です。
会話を始めたら、まずこのファイルと `knowledge/` の中身を読んでから作業してください。

## フォルダの使い分け

| フォルダ | 入れるもの |
|---|---|
| `posts/` | 自分の投稿 1件 = 1ファイル |
| `searches/` | 調べたこと・検索したこと 1件 = 1ファイル |
| `knowledge/` | 記録から見つけた「勝ちパターン」のまとめ（育てていくファイル）。`アカウント情報.md` にアカウントの軸と数字の推移がある |
| `reports/` | 週ごとの振り返りレポート |

## 1. 投稿を記録するとき（「投稿を記録して」と言われたら）

- `posts/_テンプレート.md` の形で、`posts/YYYY-MM-DD_テーマ.md` に保存する
- 足りない情報（投稿の種類、反応の数など）があれば、短く質問して埋める。わからない項目は「不明」でよい
- 数日後に反応の数を教えてもらったら、同じファイルの数字を更新する
- 保存したら、気づいたことを1〜2行だけ伝える

## 2. 調べたことを記録するとき（「検索を記録して」と言われたら）

- `searches/_テンプレート.md` の形で、`searches/YYYY-MM-DD_キーワード.md` に保存する
- 「なぜ調べたか」と「投稿にどう使えそうか」を必ず書く

## 3. 振り返りをするとき（「振り返って」と言われたら）

- `posts/` と `searches/` を全部読む
- 次の観点でパターンを探す
  - 反応（保存数・シェア数・いいね・リーチ）が良かった投稿と悪かった投稿の違い
  - 投稿の種類（フィード／リール／カルーセル／ストーリーズ）ごとの差
  - 1枚目・冒頭3秒・キャプションの書き出し・ハッシュタグ・投稿時間の傾向
  - よく調べているテーマと、実際に投稿したテーマのズレ
- 結果を `reports/YYYY-MM-DD_振り返り.md` に保存する
- `knowledge/` の各ファイルに、新しくわかったことを **追記** する（古い内容は消さない。間違いだとわかった内容は消さずに「→ 〇月〇日の振り返りで否定」と書き足す）
- データが少ないうちは「まだ仮説」と書き、言い切らない

## 4. 投稿を作るとき（「投稿案を出して」「キャプションを書いて」と言われたら）

- 必ず先に `knowledge/` を全部読み、勝ちパターンに沿って作る
- どのナレッジを使ったかを一言そえる

## パンアカウントならではのルール

- アカウントの軸は `knowledge/アカウント情報.md` にある「はじめてでも作れる・こねない・夜仕込んで朝焼くだけ」。投稿案はこの軸から外れないようにする
- レシピの分量・温度・時間は、私がくれた情報か、記録済みのレシピだけを使う。わからないときは作らずに質問する
- 楽天ROOMで紹介した道具・材料は、投稿ファイルの「中身」に書いておく
- 占いアカウントは別フォルダ（claude-占いナレッジ）。ここには混ぜない

## 書き方のルール

- 日本語で、小学生でもわかる言葉で書く
- 日付は YYYY-MM-DD の形にする
- パスワード、他人の個人情報、DMの中身などは記録しない
