# リール台本の基本の型

2026-10-12 に桜子さんが共有してくれた型。台本係はこの型で台本を書く。
ほかのルール（投稿ルールや分析の仮説）とぶつかるときは、この型が優先。

## 型（そのまま使う部分は【固定】、【 】は毎回入れかえる）

```
【固定】朝は焼きたてパンしか食べません
【固定】朝パン好きの私が作る、【料理名】。

【固定】寝かしつけから生還
【固定】夜のうちに仕込む
【工程１】（夜の工程）

【固定】冷蔵庫にあとは任せる
【固定】おやすみなさい

【工程２】（朝の工程）

【完成一言】

【固定】保存して、作ってみてね。
```

## 書き方の見本（丸パンの場合）

```
朝は焼きたてパンしか食べません
朝パン好きの私が作る、ふわふわ丸パン。

寝かしつけから生還
夜のうちに仕込む
材料を混ぜる
粉気がなくなったらちょっと休憩
30回パンチ
つるんとしたら👍

冷蔵庫にあとは任せる
おやすみなさい

お粉してはがしていく
ぽてっ　くるん　６分割　成形していくー　コロコロ
15分ベンチタイム。
ふっくらしたら牛乳をぬるよ
180℃で15分焼いていく

ほっかほか完成
ほんのり甘くて、そのままでもおいしい。
家にあったアプリコットつけたら、止まらないおいしさ

保存して、作ってみてね。
```

## ポイント
- 【工程１】【工程２】は、1行に1動作。短く、話しことばで（「ぽてっ　くるん」のような音のことばもOK）
- 【工程１】は「混ぜる → 休憩 → パンチ → つるんとしたら👍」のように、見た目の目安で区切る
- 【工程２】は「はがす → 分割・成形 → ベンチタイム → 仕上げ → 焼く」の流れ。そのパンにない工程は飛ばす
- 【完成一言】は2〜3行。①できたてのひと言 ②味・食感 ③家にあるものとの食べ方やちょっとした発見
- 数字は「パンチの回数」「ベンチタイムの時間」「焼く温度と時間」だけ。分量はキャプションに任せる
- フライパンやトースターで焼くパンは「〇℃で〇分」のところを、その道具での焼き方に置きかえる
- 締めは「保存して、作ってみてね。」だけ。前に別の定型文を足さない
